# UE_Tools

A compilation of useful tools, guides, and scripts for UE development.

## Backup game

In `scripts/back_game.py` is a Python script which generates a timestamped .zip archive from an Unreal Engine project folder.
Examplified:
```
Documents/
    LKKGameProject/
    ue_tools/
    LKKGameProject-20240606.zip
```

This .zip archive shown was generated by command-line:
```
cd Documents/
python -u ue_tools/scripts/back_game.py LKKGameProject
```

This useful tool packages the useful folders inside a project while ignoring `Intermediate`, `Build`, and generated VS solution files.
The generated .zip is space efficient and can be used for backup.
